# API Rick And Morty

Projeto desenvolvido para a disciplina de Front-End com o objetivo de consumir dados de uma API pública utilizando HTML, CSS e JavaScript puro.

## Sobre o Projeto

O site realiza o consumo da API Rick and Morty utilizando JavaScript através do método `fetch()`, exibindo dinamicamente cards dos personagens da animação.

Cada card apresenta:

* Nome do personagem
* Imagem
* Status
* Espécie
* Gênero

Os elementos são criados dinamicamente via JavaScript utilizando DOM Manipulation com funções como:

* `fetch()`
* `then()`
* `createElement()`
* `appendChild()`

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Rick and Morty API
